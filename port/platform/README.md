# platform

Implementations of the APIs the game calls, for macOS: Win32 (windows, messages,
files, threads, timers, registry, module resources read from the original binaries on
the CD) on SDL3 and POSIX; DirectDraw and Direct3D 7 drawing
in software; Miles Sound System on SDL audio; Bink and Smacker on FFmpeg. Built as the
`platform` library that every module links.
