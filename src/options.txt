# Compiler options of each original project: one line per binary, plus a line for
# each library that was built as a project of its own and linked into the binary
# (its subdirectory, ending in /). Every source file is compiled with the line of
# its directory; see tools/msvc/COMPILERS.md for the evidence. The /D<NAME>_API at the
# end of each binary's line is not the original's: the binary's own headers export their
# classes here; everywhere else those headers define <NAME>_API as dllimport.
# mflinalg.dll keeps /DMFLINALG_BUILD and mflinalg_api.h (see there).
#
